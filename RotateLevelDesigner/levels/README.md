# levels/

Thư mục lưu level của Designer. Trong tool bấm **Chọn thư mục levels…** một lần và chọn đúng thư mục này;
từ đó **Ctrl+S** ghi `<tên>.rrpack.json` vào đây và panel "Level của tôi" liệt kê các file.

- `.rrpack.json`: level đầy đủ (runtime + thiết kế + lời giải nếu đã chạy). Đây cũng là file gửi Dev;
  Dev nhập bằng Unity **IEC > TURP > Designer Tool > Import designer pack…** (hộp thoại mở sẵn thư mục này).
- `.rrdesign.json`: file thiết kế (ví dụ Codex viết). Mở được từ panel; khi lưu sẽ ghi thành `.rrpack.json` bên cạnh.
